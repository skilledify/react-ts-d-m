## 📖 О проекте

**D&M** — это одностраничное приложение (SPA) для автомобильного маркетплейса: каталог новых и подержанных автомобилей, финансовые калькуляторы, сравнение лизинга и покупки, а также сохранение понравившихся машин в избранное.

Интерфейс построен на фирменной палитре — **глубокий чёрный `#151515`** и **фирменный синий `#0066FF`**, — полностью адаптивен и работает на мобильных, планшетах и десктопах.

> 💡 Проект сочетает строгую типизацию TypeScript, компонентный подход React и современную сборку Vite — код легко расширять и поддерживать.

## 🚀 Быстрый старт

### Требования

- **Node.js** `20.19+` или `22.12+` *(рекомендуется LTS)*
- **npm** `10+` *(или `pnpm` / `yarn`)*

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/skilledify/react-ts-d-m.git

# 2. Перейдите в папку проекта
cd react-ts-d-m

# 3. Установите зависимости
npm install

# 4. Запустите dev-сервер
npm run dev
```

После запуска приложение будет доступно по адресу **http://localhost:5173/react-ts-d-m/**.

### Production-сборка

```bash
npm run build     # проверка типов + сборка в dist/
npm run preview   # локальный просмотр production-сборки
```

### Публикация на GitHub Pages

```bash
npm run deploy
```

> ⚙️ `base` в `vite.config.ts` уже настроен на `/react-ts-d-m/`, а `homepage` в `package.json` указывает на GitHub Pages. При смене имени репозитория обновите оба значения.

### npm-скрипты

| Скрипт | Описание |
| :--- | :--- |
| `npm run dev` | Запуск Vite в режиме разработки |
| `npm run build` | Проверка типов `tsc -b` и production-сборка |
| `npm run preview` | Предпросмотр собранного приложения |
| `npm run lint` | Проверка кода ESLint |
| `npm run lint:fix` | Автоматическое исправление замечаний ESLint |
| `npm run format` | Форматирование `src/**/*.{ts,tsx,css,json}` через Prettier |
| `npm run deploy` | Публикация `dist/` на GitHub Pages |

## ❤️ Как работает избранное

Избранное — глобальное состояние приложения, доступное на всех страницах:

1. **Добавление** — нажмите сердечко на карточке автомобиля в каталоге или в разделе подержанных машин.
2. **Счётчик** — количество сохранённых машин отображается на иконке в шапке.
3. **Панель** — клик по сердечку в шапке открывает список с миниатюрами, ценами и кнопками удаления.
4. **Главная страница** — блок «Saved cars» показывает всю подборку, а при пустом списке предлагает перейти в каталог.
5. **Сохранение** — данные автоматически пишутся в `localStorage` под ключом `dm-favorites` и переживают перезагрузку страницы.

```tsx
// Пример использования
const { favorites, count, isFavorite, toggleFavorite, removeFavorite } =
  useFavorites();

toggleFavorite({
  id: "catalog-1",
  title: "Toyota Crown 2023",
  price: "$650/mo",
  image: carImage,
  meta: "42 MPG · AWD",
  href: "/catalog",
});
```

## 🎨 Дизайн-система

| Токен | Значение | Применение |
| :--- | :---: | :--- |
| Ink | `#151515` | Текст, шапка, акцент «покупка» |
| Brand Blue | `#0066FF` | Кнопки, ссылки, активные состояния |
| Deep Blue | `#0052CC` | Hover-состояния |
| Sky | `#38BDF8` | Градиенты и декоративные акценты |
| Surface | `#F6F9FF` | Светлые секции и панели |
| Muted | `#6B7280` | Вторичный текст |

Стили организованы по принципу **CSS Modules + глобальные утилиты**: каждый компонент хранит собственный `.module.css`, а общие классы (`.container`, `.wrapper`, `.main`) живут в `src/index.css`.
